# Würfel-Roller

Würfel-App (d4–d100) mit Animation, Kombinationen, Vorteil/Nachteil, Sets, Ton & Vibration.

## Am Handy nutzen
- **PWA:** `index.html` über HTTPS hosten (z. B. GitHub Pages), in Chrome öffnen → „Zur Startseite hinzufügen“.
- **APK:** GitHub → Actions → „Android APK“ → Artefakt `wuerfel-roller-debug-apk` herunterladen und installieren
  (Installation aus unbekannten Quellen erlauben). Lokal: `npm install && npm run build && npx cap add android && npx cap sync android`, dann in Android Studio öffnen.
